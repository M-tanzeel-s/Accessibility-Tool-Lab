# Accessibility Tool Lab

A small accessibility lab for practicing keyboard navigation, checking color contrast, testing zoom, fixing a broken page and making a simple audit report for WCAG 2.1 AA.

It's a single HTML file. No install, no setup.

## How to run it

Download `Accessibility Tool Lab.html` and open it in your browser. It works offline too. Only the Fredoka font needs internet, and if it can't load, the page uses a normal font instead.

## What's in it

1. **Keyboard and ARIA**: tabs, accordion, dialog, menu button and a form with errors, all usable with just the keyboard. A live log shows which key you pressed and where the focus is.
2. **Contrast and zoom**: contrast checker with AA/AAA results and a suggested passing color. Also text zoom, reflow at 320px, text spacing and color blindness filters.
3. **Fix the UI**: a broken sample page next to a fixed one, plus a tracker of 14 common problems with the WCAG rule, how to spot it and how to fix it.
4. **Audit report**: a checklist of 18 WCAG rules. You can generate a report, copy it, print it or download it as a text file.
5. **Meme break**: cat memes with an accessibility lesson in each one.
6. **Cheat sheet**: the 18 rules in simple words, with search and filters.
7. **Quiz**: 8 questions with explanations and a score.

## Features

- 9 themes: light, dark, high contrast, pink, purple, golden, mint, ocean, galaxy
- Text size buttons
- Calm mode (turns off animations)
- Easy-read font option
- Points for finding and fixing issues and for your quiz score
- Progress and settings saved in the browser
- Reset button
